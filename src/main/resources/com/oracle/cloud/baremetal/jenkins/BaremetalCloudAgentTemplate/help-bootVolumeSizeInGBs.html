The size of the boot volume in gigabytes (GB) to be created for the instance.

If not specified or set to 0, the instance will use the default boot volume size of the selected image. If specified, the boot volume will be resized to the provided size at instance launch time.

The size must be greater than or equal to the minimum size of the image's boot volume. Consult your OCI environment for the maximum boot volume size limits.

Leave empty or set to 0 to use the image's default boot volume size.
